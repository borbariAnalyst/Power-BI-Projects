# 📊 Power BI Retail & Sales Insights  
### Data Technician Bootcamp – Project Summary

This Power BI project was created as part of a Data Technician bootcamp, focusing on developing strong foundational skills in data preparation, modelling, and interactive reporting. The goal was to transform raw retail and sales data into a clear, insightful, and visually engaging report that supports data‑driven decision‑making.

---

## 🚀 Project Overview

The report explores key retail and sales metrics, using Power BI to uncover trends, highlight performance differences, and support storytelling through data. It demonstrates the full workflow of a modern BI project—from cleaning and transforming data to building dynamic visuals and publishing an interactive dashboard.

---

## 🛠️ Core Skills Demonstrated

### 🔄 **Data Cleaning & Transformation (Power Query)**
- Removed duplicates, handled missing values, and standardized data formats.  
- Merged and appended tables to create a unified dataset.  
- Applied conditional columns and transformations to prepare data for analysis.
- Combining data from Excel and OData feed in Power BI
- Publishing and sharing reports

### 📐 **Data Modelling & DAX**
- Understanding relationships between tables
- Creating clean and efficient dimensional structures
- Building a structured data model suitable for reporting
- Built calculated columns for categorisation (e.g., product groups, sales bands).  
- Created DAX measures for KPIs such as:
  - Total Sales  
  - Average Order Value  
  - Year‑on‑Year Growth  
- Used time‑intelligence functions to compare performance across periods.

### 🎛️ **Interactive Reporting**
- Added slicers and filters for:
  - Date ranges  
  - Product categories  
  - Regions  
  - Customer segments  
- Enabled drill‑through and cross‑highlighting for deeper exploration.

### 📊 **Visualisations**
A variety of visuals were used to tell a clear and compelling story:

- **Bar Charts** – Top‑selling products, regional performance  
- **Line Charts** – Sales trends over time  
- **Maps** – Geographic sales insights  
- **Cards & KPIs** – Quick‑glance performance metrics  

These visuals work together to help users quickly identify patterns, outliers, and opportunities.
